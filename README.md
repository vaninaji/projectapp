
# Food Delivery Web App

This is a simple, front-end food delivery web application created as part of a group project. The app allows users to browse menu items, add them to a cart, and view a basic order summary.

## Features

* Responsive layout with a clean and modern design
* Interactive item cards with hover effects
* Functional cart system built with JavaScript
* Modular and organized HTML structure
* Smooth CSS transitions and animations
